# 简历项目描述草稿（仅在对应功能确实完成后使用）

**SpectraScholar — 面向科研领域的智能文献调研 Agent（个人二次开发项目）**

基于 GPT Researcher 开源研究引擎进行业务扩展，开发具备科研任务提交、PDF 论文管理、多论文结构化比较和证据校验能力的 Web Agent 应用。

技术栈：Python、FastAPI、Pydantic、GPT Researcher、SQLite（后续可迁移 PostgreSQL）、Docker。

个人工作（请逐条确认完成情况，不要提前全写进简历）：

- 自主设计 FastAPI 服务及研究引擎适配层，分离业务逻辑和外部 Agent SDK，提供研究任务、PDF 上传、报告下载及任务历史接口。
- 针对高光谱论文对比构建 Pydantic Schema，抽取数据集和精度指标的候选字段，并通过 PDF 页码与原文片段匹配过滤无证据数据。
- 实现失败处理、任务状态持久化及接口自动化测试，使用容器化方案完成跨环境部署。
- 构建真实论文测试集，对比优化前后的引用有效率、字段抽取正确率、任务成功率、时延和 API 成本（**填实际结果**）。

面试说明：通用研究与搜索能力来自 Apache-2.0 上游框架。自己主要负责领域业务层、接口架构、信息抽取可信性与可测性、部署。
