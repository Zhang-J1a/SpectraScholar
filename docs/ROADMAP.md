## 下一阶段优先级

1. **真实评测**（最高）：10 个真实任务、3 篇合法论文、真实 embedding、成本/耗时。
2. **表格/OCR**：带线结构表已支持；下一步是复杂表头/跨页表与扫描件 OCR。
3. **任务队列**：Redis/RQ + 取消 + 预算。
4. **多用户/持久化升级**：PostgreSQL + pgvector。
5. **LangGraph**：只有在节点契约和真实失败案例稳定后再考虑。
6. **截图/视频**：在普通桌面环境完成，不伪造。
